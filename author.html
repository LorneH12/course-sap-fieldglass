Content studio

Load this course’s assets/course.json, edit the structured content, validate, and download a replacement. Then run python3 scripts/build.py to regenerate the player content and SCORM package. This editor makes no network requests and does not save files automatically.

Validation checks the data shape and answer keys, not instructional accuracy. Review the source, scenarios and feedback using the production SOP before release. This editor supports the six shared-player courses; Bloom’s uses its separate content and interaction files.
